# Lattice icon set

Master: lattice.svg (512 px tile). Small sizes (<= 32 px): lattice-small.svg (bars only).
Tray: lattice-tray-mono.svg (white bars, no tile).
Animated: lattice-loading.svg (splash/loading), lattice-connecting.svg (joining a call), lattice-speaking.svg (speaking indicator); all respect prefers-reduced-motion.
Generated: png/ (16-1024), lattice.ico (Windows, 16-256).
Android adaptive icon: android/ic_launcher_foreground.svg (+ monochrome for themed icons), background #101013.
Palette: tile #101013, border #26262d, accent #6875f5, light bar #eef0ff.
